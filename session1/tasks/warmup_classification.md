# Warm-up (Topic 1.1, pairs, 8 min): Which type of ML?
For each problem: supervised (classification/regression), unsupervised, or RL — and why.

1. Predict whether a loan applicant will default, from past labeled loans.
2. Group 40,000 customers into "similar shopper" segments — no labels exist.
3. Learn to set delivery-drone throttle from crash/success feedback in simulation.
4. Estimate next month's sales for each store.
5. Flag transactions that look unlike anything seen before.
6. Decide which ad to show next, learning from clicks over time.

**Key (instructor):** 1 supervised-classification · 2 unsupervised-clustering ·
3 RL · 4 supervised-regression · 5 unsupervised-anomaly ·
6 RL (bandit; accept supervised-with-feedback answers with discussion).
